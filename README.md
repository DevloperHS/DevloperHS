## 🚀 Selected work

**Agents and AI products**

- [**ShortPay**](https://github.com/DevloperHS/ShortPay): audits freight invoice surcharges before payment. The money math is plain code with no LLM, models only read the documents, and a human approves exceptions.
- [**Contextio**](https://github.com/DevloperHS/contextio): a memory layer that turns each Telegram group into its own searchable knowledge base, with LLM agents that retrieve and rerank evidence.
- [**Qwen Deep Researcher**](https://github.com/DevloperHS/qwen_deep_researcher): a fully local research agent on LangGraph that searches, reflects on gaps and writes a cited report.
- [**Agentic CLI**](https://github.com/DevloperHS/agentic_cli_tool): a command-line agent that takes plain English, built twice (Claude Code and Gemini CLI) with Composio.
- [**Agents SDK Tests**](https://github.com/DevloperHS/agents-sdk-tests): the same Composio-powered agent built with the OpenAI, Google ADK and Claude Agent SDKs, side by side.
- [**Commute Zen**](https://github.com/DevloperHS/commute-zen-agent): a voice-first news assistant on Gemini Live that gives calm, personal commute briefings.

**Evals and comparisons**

- [**LLM Comparison**](https://github.com/DevloperHS/llm_comparison): different models tested on the same project.
- [**LangSmith Agent Builder Builds**](https://github.com/DevloperHS/langsmith-agent-builder-builds): a look behind the scenes of three specialised agents.

**Products and tools**

- [**Buffer Clip**](https://github.com/DevloperHS/buffer_clip): a Chrome extension and in-browser editor that turns screen recordings into polished demos with auto-zooms and 4K export.
- [**3dify**](https://github.com/DevloperHS/3dify): turns one photo into a 3D asset you can view in the browser.
- [**GlobalClimateLens**](https://github.com/DevloperHS/banni-climate-lens): satellite-data analytics for long-term environmental change, starting with the Banni Grasslands (2001 to 2024).

**Games and 3D demos**

- [**Perihelion**](https://github.com/DevloperHS/space-walk): a procedural first-person asteroid ride through the Solar System, with no external textures, models or audio.
- [**Night Circuit**](https://github.com/DevloperHS/night-circuit): a neon night arcade racer in Three.js with drift handling and AI rivals.
- [**Meteor Impact Revival**](https://github.com/DevloperHS/meteor-city-revival): rain meteors on a procedural city that fights back. [Play it](https://meteor-city-revival.vercel.app).
- [**Mars Sim**](https://github.com/DevloperHS/mars-sim): a real-time WebGPU simulation of Gale Crater and the Bagnold Dunes.
